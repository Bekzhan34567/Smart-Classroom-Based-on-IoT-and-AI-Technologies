# Smart Classroom - Усиленная версия для дипломной работы

## Обзор проекта

Smart Classroom - это AI-платформа для управления учебным процессом с предиктивной аналитикой и рекомендательными системами. Проект усилен современным дизайном, машинным обучением и улучшенной безопасностью.

## Основные улучшения

### 🎨 Frontend (Современный UI)

**Технологии:**
- React 19 + Vite
- TailwindCSS для стилизации
- shadcn/ui компоненты (Radix UI)
- Lucide React иконки
- Recharts для визуализации данных

**Улучшения:**
- Полностью переработанный дизайн с современным интерфейсом
- Адаптивная навигация с табами
- Красивый дашборд с метриками
- Интерактивные графики и визуализация данных
- Улучшенная страница авторизации с современными формами
- Градиентные карточки и современная цветовая схема

### 🤖 AI и Машинное обучение

**ML модули:**
- **Предиктивная аналитика успеваемости** - ML модель (Gradient Boosting) для прогнозирования оценок
- **Детекция рисков** - Random Forest для выявления студентов группы риска
- **Рекомендательная система** - персональные рекомендации для студентов
- **Детекция аномалий** - выявление нестандартного поведения (z-score анализ)

**API endpoints:**
- `GET /ml-analytics/predictions` - предсказания для всех студентов
- `GET /ml-analytics/predictions/{student_id}` - предсказание для конкретного студента
- `GET /ml-analytics/recommendations/courses` - рекомендации для курсов
- `GET /ml-analytics/anomalies` - обнаруженные аномалии
- `GET /ml-analytics/summary` - сводка ML аналитики

### 🔒 Безопасность и Валидация

**Улучшения:**
- Модуль безопасности с валидацией данных
- Проверка сложности паролей
- Валидация email и пользовательских данных
- Sanitization ввода для защиты от XSS
- JWT токены с настройками безопасности
- Rate limiting (заготовка для Redis)
- Улучшенная конфигурация с pydantic-settings

**Валидация:**
- Студентов: ФИО, email, группа
- Преподавателей: ФИО, email, предмет
- Курсов: название, преподаватель
- Паролей: сложность (8+ символов, заглавные, цифры, спецсимволы)

### 📊 Визуализация данных

**Графики и дашборды:**
- Производительность студентов (посещаемость vs оценки)
- Динамика оценок по месяцам
- Распределение рисков по категориям
- AI предсказания с прогресс-барами
- Метрики в реальном времени (студенты, курсы, посещаемость, риски)

### 📝 Логирование

**Система логирования:**
- Детальные логи в файлы
- Отдельные логи ошибок
- Консольные логи для разработки
- Форматирование с временными метками
- Ротация логов по дням

## Установка и запуск

### Backend

```bash
cd smart_classroom_backend

# Создать виртуальное окружение
python -m venv .venv
source .venv/bin/activate  # На Windows: .venv\Scripts\activate

# Установить зависимости
pip install -r requirements.txt

# Настроить .env файл
cp .env.example .env

# Запустить сервер
uvicorn app.main:app --reload
```

Backend будет доступен на `http://127.0.0.1:8000`
API документация: `http://127.0.0.1:8000/docs`

### Frontend

```bash
cd smart_classroom_frontend

# Установить зависимости
npm install

# Запустить dev сервер
npm run dev
```

Frontend будет доступен на `http://127.0.0.1:5173`
